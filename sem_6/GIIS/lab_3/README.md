## 1. Цель работы

Разработать элементарный графический редактор, реализующий построение параметрических кривых:

- **форма Эрмита**
- **форма Безье**
- **кубический равномерный B-сплайн**

Выбор метода выполняется из меню и через панель инструментов **«Кривые»**.

## 2. Теоретические сведения

### 2.1. Общий вид параметрической кривой

Кривая задаётся параметром \(t \in [0, 1]\):

\[
\mathbf{P}(t) = \big(x(t), y(t)\big)
\]

Для кубических кривых:

\[
\mathbf{P}(t) = \mathbf{T}\mathbf{M}\mathbf{G},
\quad
\mathbf{T} = [t^3,\ t^2,\ t,\ 1]
\]

где \(\mathbf{M}\) — матрица базиса, \(\mathbf{G}\) — матрица геометрии (контрольных данных).

### 2.2. Кубическая кривая Эрмита

Форма Эрмита задаётся двумя точками и двумя касательными:

- \( \mathbf{P}_0 \) — начало,
- \( \mathbf{P}_1 \) — конец,
- \( \mathbf{R}_0 \), \( \mathbf{R}_1 \) — векторы касательных.

\[
\mathbf{P}(t)=h_1(t)\mathbf{P}_0 + h_2(t)\mathbf{P}_1 + h_3(t)\mathbf{R}_0 + h_4(t)\mathbf{R}_1
\]

где базисные функции:

- \(h_1(t)=2t^3-3t^2+1\)
- \(h_2(t)=-2t^3+3t^2\)
- \(h_3(t)=t^3-2t^2+t\)
- \(h_4(t)=t^3-t^2\)

В программе касательные задаются не напрямую, а через дополнительные точки:
\[
\mathbf{R}_0 = \mathbf{T}_0 - \mathbf{P}_0,\quad \mathbf{R}_1 = \mathbf{T}_1 - \mathbf{P}_1
\]

### 2.3. Кубическая кривая Безье

Для 4 контрольных точек \(\mathbf{P}_0,\mathbf{P}_1,\mathbf{P}_2,\mathbf{P}_3\):

\[
\mathbf{P}(t) = (1-t)^3\mathbf{P}_0 + 3t(1-t)^2\mathbf{P}_1 + 3t^2(1-t)\mathbf{P}_2 + t^3\mathbf{P}_3
\]

Свойства:

- проходит через \(\mathbf{P}_0\) и \(\mathbf{P}_3\),
- \(\mathbf{P}_1,\mathbf{P}_2\) задают форму и касательные на концах.

### 2.4. Кубический равномерный B-сплайн

Каждый сегмент определяется 4 соседними опорными точками:
\[
\mathbf{P}_{i}, \mathbf{P}_{i+1}, \mathbf{P}_{i+2}, \mathbf{P}_{i+3}
\]

\[
\mathbf{C}(t)=B_0(t)\mathbf{P}_i+B_1(t)\mathbf{P}_{i+1}+B_2(t)\mathbf{P}_{i+2}+B_3(t)\mathbf{P}_{i+3}
\]

где:

- \(B_0(t)=\frac{-t^3+3t^2-3t+1}{6}\)
- \(B_1(t)=\frac{3t^3-6t^2+4}{6}\)
- \(B_2(t)=\frac{-3t^3+3t^2+3t+1}{6}\)
- \(B_3(t)=\frac{t^3}{6}\)

Кривая локально управляемая: изменение одной опорной точки влияет только на соседние сегменты.

### 2.5. Стыковка сегментов

Для последовательного построения сегментов конец предыдущего сегмента автоматически становится началом следующего:

- для Эрмита: \(P_1^{(k)} = P_0^{(k+1)}\),
- для Безье: \(P_3^{(k)} = P_0^{(k+1)}\).

Это обеспечивает геометрическую непрерывность \(C^0\) (неразрывность по положению).

## 3. Описание программы

### 3.1. Структура проекта

| Файл | Назначение |
|------|------------|
| `algorithms.py` | Реализация формул Эрмита, Безье и B-сплайна |
| `editor.py` | GUI-редактор (tkinter): меню/панель «Кривые», режим корректировки и стыковки |
| `requirements.txt` | Доп. зависимости отсутствуют |

### 3.2. Реализованные требования

- Выбор метода из меню **«Кривые»** и из панели инструментов.
- Построение:
  - Эрмита (4 точки на сегмент),
  - Безье (4 точки на сегмент),
  - B-сплайн (произвольный набор опорных точек, начиная с 4).
- Режим корректировки опорных точек: перетаскивание мышью.
- Режим стыковки сегментов для Эрмита и Безье.
- Очистка сцены и удаление последнего сегмента/точки текущего метода.

## 5. Порядок работы

1. Выбрать тип кривой: **Эрмита / Безье / B-сплайн**.
2. В режиме построения добавлять точки ЛКМ.
3. Для Эрмита и Безье после 4 точек строится сегмент.
4. Для B-сплайна кривая строится автоматически при количестве точек \(\ge 4\).
5. Включить **режим корректировки**, чтобы перемещать опорные точки.
6. Включить **стыковку**, чтобы строить связные сегменты подряд.
