## 1. Цель работы

Разработать элементарный графический редактор, реализующий построение линий второго порядка:

- **окружность**
- **эллипс**
- **гипербола**
- **парабола**

Выбор кривой задаётся из пункта меню и доступен через панель инструментов **«Линии второго порядка»**. В редакторе предусмотрен **отладочный режим**, в котором отображается пошаговое решение на дискретной сетке и полная таблица хода решения (откуда берутся точки).

---

## 2. Теоретические сведения

### 2.1. Окружность

Уравнение: \(x^2 + y^2 = R^2\). Ошибка \(\Delta = x^2 + y^2 - R^2\): на кривой \(\Delta = 0\), внутри \< 0, снаружи \> 0.

Алгоритм Брезенхема генерирует первый квадрант от точки \((0, R)\) по часовой стрелке. На каждом шаге выбирается один из трёх пикселей-претендентов: горизонтальный H \((x+1, y)\), вертикальный V \((x, y-1)\), диагональный D \((x+1, y-1)\). Выбор по знаку \(\Delta\) и вспомогательным величинам \(\delta\), \(\delta^*\) (см. таблицу 2.1 практикума). Начальное значение ошибки: \(\Delta_1 = 2 - 2R\). Полная окружность получается отражением сгенерированной дуги относительно осей и прямой \(y = x\).

### 2.2. Эллипс

Уравнение: \(\frac{x^2}{a^2} + \frac{y^2}{b^2} = 1\). Переписывается в виде \(b^2 x^2 + a^2 y^2 - a^2 b^2 = 0\). Вводится ошибка \(\Delta = b^2 x^2 + a^2 y^2 - a^2 b^2\). Генерация первого квадранта от \((0, b)\) по часовой стрелке; выбор пикселей H, V, D по таблице 2.2 практикума. Полный эллипс — отражение по осям.

### 2.3. Гипербола

Уравнение: \(\frac{x^2}{a^2} - \frac{y^2}{b^2} = 1\). В первом квадранте \(x \geq a\). Функция \(F(x,y) = b^2 x^2 - a^2 y^2 - a^2 b^2\) на кривой равна нулю. Используется метод средней точки: шаг по \(x\), выбор следующего \(y\) по знаку \(F\) в средней точке.

### 2.4. Парабола

Уравнение: \(y^2 = 2px\). В первом квадранте \(x = \frac{y^2}{2p}\). Генерация по шагам \(y\); для каждого \(y\) вычисляется \(x\) и выводятся симметричные точки.

## 3. Описание программы

### 3.1. Структура проекта

| Файл | Назначение |
|------|------------|
| `algorithms.py` | Окружность (Брезенхем), эллипс (Брезенхем), гипербола (средняя точка), парабола; функции возвращают списки пикселей и пошаговые данные для отладки. |
| `editor.py` | GUI (tkinter): меню и панель «Линии второго порядка», холст с дискретной сеткой, панель параметров (гипербола/парабола), отладочная панель с таблицей хода решения. |
| `requirements.txt` | Зависимости не требуются (Python 3, tkinter). |

### 3.2. Реализованные требования

- **Меню «Линии второго порядка»:** выбор кривой (Окружность, Эллипс, Гипербола, Парабола), переключатель отладочного режима, очистка, выход.
- **Панель инструментов «Линии второго порядка»:** те же действия.
- **Ввод данных:**  
  - **Окружность:** 2 клика (центр, точка на окружности; радиус = расстояние).  
  - **Эллипс:** 3 клика (центр, конец полуоси \(a\) по горизонтали, конец полуоси \(b\) по вертикали).  
  - **Гипербола:** 1 клик (центр), параметры \(a\), \(b\), \(x_{max}\) в панели слева, кнопка «Построить».  
  - **Парабола:** 1 клик (вершина), параметры \(p\), \(y_{max}\) в панели, кнопка «Построить».
- **Отладочный режим:** пошаговое отображение последней построенной кривой на сетке (кнопки «Шаг назад» / «Шаг вперёд»); справа — полная таблица хода с пояснениями (Δ, δ, δ*, пиксель для окружности/эллипса; x, y, F для гиперболы; y, x для параболы). Текущий шаг помечается «>>>».

## 4. Результаты работы

### 4.1. Запуск

```bash
cd GIIS/lab_2
python editor.py
```

### 4.2. Порядок работы

1. Выбрать кривую в меню или на панели «Линии второго порядка».
2. При необходимости включить «Отладочный режим».
3. Построить кривую:
   - **Окружность:** клик — центр, клик — точка на окружности.
   - **Эллипс:** клик — центр, клик — конец оси \(a\), клик — конец оси \(b\).
   - **Гипербола:** клик — центр, ввести \(a\), \(b\), \(x_{max}\) → «Построить (после 1-го клика)».
   - **Парабола:** клик — вершина, ввести \(p\), \(y_{max}\) → «Построить (после 1-го клика)».
4. В отладочном режиме просматривать шаги и таблицу справа; текущий шаг выделен на сетке и отмечен «>>>» в таблице.

## 5. Алгоритмическая оценка

- **Окружность (Брезенхем):** генерация одной восьмой окружности за \(O(R)\) шагов; только целочисленные операции; полная окружность — 8 отражений.
- **Эллипс:** \(O(a + b)\) шагов в первом квадранте; целочисленная арифметика по таблице 2.2.
- **Гипербола:** \(O(x_{max} - a)\) шагов; вычисление \(F\) в средней точке.
- **Парабола:** \(O(y_{max})\) шагов; на каждом шаге одно деление для \(x = y^2/(2p)\).
