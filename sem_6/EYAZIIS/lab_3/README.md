# Лабораторная работа №3 — Синтаксический анализ текста

## Назначение

Приложение для автоматического синтаксического анализа текста естественного языка (dependency parsing). Использует spaCy для построения деревьев зависимостей.

## Установка

```bash
pip install -r requirements.txt
python -m spacy download en_core_web_sm
```

Для русского языка (опционально):
```bash
python -m spacy download ru_core_news_sm
```

## Запуск

```bash
python app_gui.py
```

## Функциональность

- **Входные данные:** текст на естественном языке  
- **Форматы:** TXT, RTF, PDF, HTML, DOC, DOCX  
- **Выходные данные:** структуры синтаксического анализа (деревья зависимостей)  
- GUI с просмотром, редактированием, сохранением результатов  
- Справка  
- Визуализация дерева зависимостей в браузере  

## Структура

- `text_extractor.py` — извлечение текста из документов  
- `syntactic_analyzer.py` — библиотека синтаксического анализа (spaCy)  
- `app_gui.py` — графический интерфейс
