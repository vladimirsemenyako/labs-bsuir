# Лабораторная работа 1. Модель арифметического конвейера (вариант 2)

**Тема:** Программирование операций обработки данных и знаний с конвейеризированной обработкой потока данных.

**Цель:** Реализация и исследование модели решения на конвейерной архитектуре задачи вычисления попарного произведения компонентов двух векторов чисел.

**Вариант 2:** Алгоритм вычисления произведения пары 4-разрядных чисел умножением с младших разрядов со сдвигом частичной суммы вправо.

## Требования к модели

- Визуальное отображение пошагового процесса умножения; на каждой стадии — данные (двоично), индекс пары, время от старта.
- До первой стадии — не менее 3 пар элементов векторов в десятичном виде.
- После последней стадии — не менее 3 элементов результирующего вектора с номерами и временем получения.
- Время в условных единицах (такты).
- Параметры: время такта стадии `ti`, число стадий `n`, длина векторов `m`.

## Запуск (CLI)

```bash
python3 cli.py [опции]
```

**Опции:**

- `-n, --stages` — число стадий конвейера (по умолчанию 4).
- `-m, --pairs` — число пар (длина векторов), по умолчанию 8.
- `-t, --stage-time` — время одного такта в условных единицах (по умолчанию 1.0).
- `--seed` — зерно ГПСЧ для воспроизводимой генерации векторов.
- `--no-animate` — вывести только входные пары, результаты и сводку, без пошаговой развёртки по тактам.

**Примеры:**

```bash
# Полная пошаговая развёртка (m=5, ti=1)
python3 cli.py -m 5 -t 1

# Только итог (без анимации)
python3 cli.py -m 8 -t 1 --no-animate

# Воспроизводимые данные
python3 cli.py -m 6 --seed 42
```

## Структура

- `pipeline.py` — ядро: алгоритм умножения 4-разрядных чисел (LSB, сдвиг частичной суммы вправо), симуляция конвейера, формат двоичного вывода (группы по 4 символа).
- `cli.py` — интерфейс командной строки, ввод параметров и вывод по требованиям ЛР.

## Алгоритм (вариант 2)

Регистр частичной суммы 8 бит. На каждом из 4 шагов (по разряду множителя с младшего):

1. Если текущий разряд множителя равен 1 — прибавить множимое, сдвинутое в старшую половину регистра (`a << 4`).
2. Сдвинуть частичную сумму вправо на 1 разряд.

После 4 шагов в регистре — произведение `A*B` (8 бит).
