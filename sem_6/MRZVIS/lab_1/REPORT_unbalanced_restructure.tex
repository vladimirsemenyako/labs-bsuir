\subsubsection*{Дан несбалансированный конвейер. Каким образом можно перестроить конвейер, чтобы для заданного $r_0$ выполнялось $e(n, r_0) > e_0$?}

Исходные данные предыдущего вопроса: $n = 4$, $e_0$ задана, ищем условия по $r_0$. Для несбалансированного конвейера
\[
T_1 = r_0 \sum_{i=1}^{n} t_i, \quad T_n = \sum_{i=1}^{n} t_i + (r_0 - 1) t_{\max}, \quad e(n, r_0) = \frac{r_0 \sum_{i=1}^{n} t_i}{n \left( \sum_{i=1}^{n} t_i + (r_0 - 1) t_{\max} \right)}.
\]

Чтобы для \textbf{заданного} $r_0$ выполнялось $e(n, r_0) > e_0$, конвейер можно перестроить следующими способами.

\paragraph{1. Сбалансировать конвейер.}
Привести все времена стадий к одному значению (например, $t_i = t$ для всех $i$). Тогда $t_{\max} = t$, $\sum t_i = n t$, и
\[
e = \frac{r_0 n t}{n \bigl( n t + (r_0 - 1) t \bigr)} = \frac{r_0}{n + r_0 - 1}.
\]
Для заданных $r_0$ и $e_0$ неравенство $e > e_0$ даёт $r_0 > e_0(n + r_0 - 1)$, откуда
\[
n < 1 + \frac{r_0(1 - e_0)}{e_0}.
\]
Если текущее число стадий $n$ не удовлетворяет этому условию, стадии объединяют, уменьшая $n$ до значения
\[
n \leq n_{\max} = \left\lfloor 1 + \frac{r_0(1 - e_0)}{e_0} \right\rfloor.
\]

\paragraph{2. Уменьшить число стадий $n$.}
При той же балансировке эффективность $e = r_0/(n + r_0 - 1)$ тем выше, чем меньше $n$. Поэтому объединение этапов (уменьшение $n$) при сохранении суммарной работы увеличивает $e$ и способствует выполнению $e > e_0$.

\paragraph{3. Уменьшить $t_{\max}$ при фиксированной сумме $\sum t_i$.}
В формуле $e$ знаменатель содержит $(r_0 - 1) t_{\max}$. При заданных $r_0$ и $n$ уменьшение максимального времени стадии (выравнивание загрузки этапов) уменьшает $T_n$ и увеличивает $e$. Имеет смысл перераспределить работу так, чтобы самые длинные стадии укоротить за счёт более равномерного распределения операций.

\paragraph{Подстановка (исходные данные: $n = 4$, $e_0 = 0{,}5$, $r_0$ задано).}
Требование $e > e_0$ после балансировки даёт $n < 1 + r_0(1 - e_0)/e_0 = 1 + r_0$. При $r_0 = 4$: $n < 5$, т.е. $n \leq 4$ — уже выполняется. При $r_0 = 2$: $n < 3$, т.е. нужно уменьшить число стадий до $n \leq 2$ (объединить этапы в два).

\textbf{Ответ:} перестроить конвейер можно так: (1) сбалансировать стадии (выровнять $t_i$); (2) уменьшить число стадий $n$ до выполнения $n < 1 + r_0(1 - e_0)/e_0$; (3) уменьшить $t_{\max}$ при неизменной сумме $\sum t_i$, перераспределив работу между этапами.
