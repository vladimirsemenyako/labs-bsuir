\subsubsection*{Определить значение $r_0$, при котором выполняется $e(n, r_0) > e_0$}

Используем обозначения сбалансированного конвейера ($t_i = \mathrm{const}$): $T_1 = r_0 n$, $T_n = n + r_0 - 1$, откуда
\[
e(n, r_0) = \frac{K_y}{n} = \frac{T_1}{T_n \cdot n} = \frac{r_0 n}{(n + r_0 - 1) n} = \frac{r_0}{n + r_0 - 1}.
\]

Требуется найти $r_0$, при котором $e(n, r_0) > e_0$, т.е.
\[
\frac{r_0}{n + r_0 - 1} > e_0.
\]

Считаем $r_0 \geq 1$, $n \geq 1$, $0 < e_0 < 1$. Знаменатель $n + r_0 - 1 > 0$. Умножаем обе части неравенства на него:
\[
r_0 > e_0 (n + r_0 - 1).
\]

Раскрываем скобки и переносим слагаемые с $r_0$ в одну сторону:
\[
r_0 > e_0 n + e_0 r_0 - e_0, \quad r_0 - e_0 r_0 > e_0 n - e_0, \quad r_0(1 - e_0) > e_0(n - 1).
\]

При $e_0 < 1$ выражение $(1 - e_0) > 0$, делим на него без смены знака:
\[
r_0 > \frac{e_0 (n - 1)}{1 - e_0}.
\]

\textbf{Формула:} минимальное (пороговое) значение ранга $r_0$, при котором эффективность превышает $e_0$:
\[
\boxed{r_0 > \frac{e_0 (n - 1)}{1 - e_0}}.
\]

Условие применимости: $r_0 \geq 1$, $n > 1$, $0 < e_0 < 1$.

\paragraph{Подстановка параметров модели.}
Для варианта 2: $n = 4$ (число стадий). Тогда
\[
r_0 > \frac{e_0 (4 - 1)}{1 - e_0} = \frac{3 e_0}{1 - e_0}.
\]

Примеры:
\begin{itemize}
    \item при $e_0 = 0{,}5$: $r_0 > \dfrac{3 \cdot 0{,}5}{1 - 0{,}5} = \dfrac{1{,}5}{0{,}5} = 3$; достаточно $r_0 \geq 4$;
    \item при $e_0 = 0{,}8$: $r_0 > \dfrac{3 \cdot 0{,}8}{0{,}2} = 12$; достаточно $r_0 \geq 13$;
    \item при $e_0 = 0{,}9$: $r_0 > \dfrac{2{,}7}{0{,}1} = 27$; достаточно $r_0 \geq 28$.
\end{itemize}

Ответ: искомое значение $r_0$ задаётся неравенством $r_0 > \dfrac{e_0 (n - 1)}{1 - e_0}$; для $n = 4$ получаем $r_0 > \dfrac{3 e_0}{1 - e_0}$. В качестве $r_0$ берётся наименьшее целое, удовлетворяющее этому неравенству.
