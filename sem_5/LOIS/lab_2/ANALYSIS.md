# Анализ кода: Важные функции для диаграмм

## 🔴 ОСОБО ВАЖНЫЕ ФУНКЦИИ (обязательно для диаграмм)

### 1. **`main()`** - Главная функция координации
**Строки:** 218-323  
**Роль:** Координирует весь процесс решения обратной задачи нечеткого вывода  
**Почему важно:** 
- Является точкой входа в программу
- Управляет последовательностью выполнения всех этапов
- Организует поток данных между функциями
- **Диаграмма:** Показывает общий алгоритм работы программы (блок-схема или диаграмма последовательности)

**Этапы работы:**
1. Парсинг входных данных (`parse_input_file`)
2. Решение отдельных уравнений для каждого столбца (`solve_single_equation`)
3. Объединение решений через пересечение (`intersect_solutions`)
4. Формирование и вывод финального ответа

---

### 2. **`solve_single_equation(r_vals, target, row_names)`** - Решение одного уравнения
**Строки:** 80-152  
**Роль:** Решает уравнение вида `min(1, sum(min(var_i, r_i))) = target`  
**Почему важно:**
- Содержит основную математическую логику решения
- Обрабатывает различные случаи (одна переменная, две переменные)
- Генерирует множества решений (прямоугольники и линии)
- **Диаграмма:** Показывает логику разветвления по случаям (диаграмма решений/дерево решений)

**Ключевые случаи:**
- Одна переменная: `min(1, min(a, r)) = target`
- Две переменные: 4 случая в зависимости от соотношения `a` и `r_a`, `b` и `r_b`
  - Случай 1: `a < r_a` и `b < r_b` → линия `a + b = target`
  - Случай 2: `a < r_a` и `b >= r_b` → прямоугольник с фиксированным `a`
  - Случай 3: `a >= r_a` и `b < r_b` → прямоугольник с фиксированным `b`
  - Случай 4: `a >= r_a` и `b >= r_b` → прямоугольник

---

### 3. **`intersect_solutions(sol1, sol2)`** - Пересечение множеств решений
**Строки:** 154-216  
**Роль:** Находит пересечение двух множеств решений от разных уравнений  
**Почему важно:**
- Критическая операция для комбинирования решений
- Реализует сложную логику пересечения разных типов множеств (прямоугольник×прямоугольник, линия×линия, линия×прямоугольник)
- Определяет совместимость ограничений
- **Диаграмма:** Показывает алгоритм пересечения (блок-схема с условиями)

**Типы пересечений:**
- Box × Box: простое пересечение интервалов
- Line × Line: проверка равенства сумм
- Line × Box: сложное пересечение с учетом ограничения суммы

---

### 4. **`Interval.intersect(self, other)`** - Пересечение интервалов
**Строки:** 12-18  
**Роль:** Находит пересечение двух интервалов  
**Почему важно:**
- Базовая математическая операция
- Используется во всех операциях пересечения
- Проверяет пустоту пересечения
- **Диаграмма:** Показывает геометрическую логику пересечения интервалов

---

### 5. **`parse_input_file(filename)`** - Парсинг входных данных
**Строки:** 43-78  
**Роль:** Читает и парсит файл с данными R(x,y) и Y(y)  
**Почему важно:**
- Преобразует текстовый формат в структуры данных
- Использует регулярные выражения для извлечения данных
- Формирует словари для дальнейшей обработки
- **Диаграмма:** Показывает структуру данных и процесс парсинга (диаграмма классов или диаграмма последовательности)

## 📊 Рекомендации по диаграммам

### Для отчета рекомендуется создать:

1. **Общая блок-схема алгоритма** (`main()`)
   - Показывает весь процесс от входа до выхода
   - Включает все основные этапы

2. **Диаграмма решения уравнения** (`solve_single_equation()`)
   - Показывает разветвление по случаям
   - Демонстрирует логику для разных типов решений

3. **Диаграмма пересечения решений** (`intersect_solutions()`)
   - Показывает алгоритм пересечения разных типов множеств
   - Включает проверки совместимости

4. **Диаграмма классов** (опционально)
   - Класс `Interval` с методом `intersect`
   - Класс `SolutionSet` с типами 'box' и 'line'

5. **Диаграмма последовательности** (опционально)
   - Взаимодействие между функциями в процессе решения
